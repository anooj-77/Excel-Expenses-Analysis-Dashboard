# 📊 Expenses Analysis Dashboard | FY 2020–2027

## Project Overview

The **Expenses Analysis Dashboard (FY 2020–2027)** is an interactive financial data analysis and visualization project developed using Microsoft Excel. The dashboard is designed to provide a clear and comprehensive overview of organizational expenses, budget allocation, departmental spending, monthly expense patterns, and payment methods.

The project transforms financial transaction data into meaningful visual insights through interactive charts, KPI indicators, and filtering capabilities. It enables users to monitor spending performance, evaluate budget utilization, compare departmental expenses, and understand financial trends through a centralized dashboard.

The dashboard combines multiple analytical views into a single interface, making complex financial information easier to understand, explore, and interpret.

## 🎯 Project Objectives

The primary objective of this project is to develop an interactive Excel dashboard that simplifies financial expense analysis and improves the presentation of financial information.

Key objectives include:

- Analyze overall organizational expenses and budget utilization.
- Monitor expenses across different departments.
- Understand the distribution of expenses by category.
- Identify monthly spending patterns and trends.
- Compare actual expenses against allocated budgets.
- Analyze the distribution of expenses across different payment methods.
- Present important financial metrics through an organized dashboard.
- Provide interactive filtering options for exploring specific departments and months.

---

## 📌 Key Performance Indicators (KPIs)

The dashboard includes six major KPI indicators to provide an immediate overview of financial performance.

| KPI | Description |
|---|---|
| Total Expenses | Displays the overall expenses recorded in the dataset. |
| Budget Allocated | Represents the total budget allocated for expenses. |
| Budget Remaining | Shows the remaining budget after accounting for expenses. |
| Transactions | Displays the total number of recorded transactions. |
| Approval Rate | Represents the percentage of transactions approved. |
| Average Expenses | Displays the average expense value. |

These indicators help users quickly understand the financial position without having to examine individual transaction records.

## 📊 Dashboard Analysis & Visualizations

The dashboard contains several analytical sections, each designed to examine a different aspect of financial performance.

### 1. Expenses by Department

This analysis visualizes the distribution of expenses across different organizational departments.

Departments included:
- Engineering
- Finance
- HR
- Marketing
- Operations
- Sales

A column chart is used to compare departmental spending and identify departments with relatively higher or lower expenses.

### 2. Expenses by Category

This section analyzes how total expenses are distributed across different spending categories.

Categories include:
- Consulting
- Equipment
- Marketing
- Office Supplies
- Software
- Training
- Travel
- Utilities

A doughnut chart provides a visual representation of category-wise expense distribution, making it easier to compare spending proportions.

### 3. Monthly Expense Trend

This visualization presents the monthly movement of expenses throughout the year.

Using a line chart, users can examine changes in spending from January to December, identify fluctuations, and observe monthly expense patterns.

This analysis helps provide a better understanding of how organizational expenses change over time.

### 4. Budget vs Actual Analysis

This section compares actual expenses with the allocated budget for each department.

The clustered column chart displays two measures:
- Actual Expenses
- Budget Allocated

This comparison helps evaluate budget utilization and identify differences between planned allocations and actual spending.

### 5. Expenses by Payment Methods

This analysis examines how expenses are distributed across different payment methods.

Payment methods included:
- Credit Card
- Cheque
- Cash
- Bank Transfer

A horizontal bar chart is used to compare payment method totals and understand the distribution of financial transactions.

## 🎛️ Interactive Dashboard Features

The dashboard includes interactive filtering functionality to make data exploration easier.

### Department Filter
Allows users to select specific departments and explore the corresponding expense information.

### Month Filter
Allows users to filter the dashboard by individual months, making it possible to examine expenses for selected periods.

### Dynamic Analysis
The interactive filtering system allows users to explore different combinations of departments and months and examine the corresponding financial information.

These interactive elements make the dashboard more flexible and useful for exploring financial data.
